Сайт-визитка: Портфолио разработчика.

Файлы:
main.py — весь код Python.
templates/index.html — главная страница.
templates/draws.html — страница фото и изображений.
requirements.txt — зависимости.

Установка:
python -m venv venv
venv\Scripts\activate (Windows),  source venv/bin/activate (Mac/Linux) или source venv/Scripts/activate (Bash)
pip install -r requirements.txt

Запуск:
python main.py runserver

Открыть в браузере:
http://127.0.0.1:8000/
